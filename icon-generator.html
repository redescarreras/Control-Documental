Generador de Iconos PNG

Para que la PWA funcione correctamente en todos los dispositivos, se necesitan iconos PNG de 192x192 y 512x512 píxeles.

SVG 192x192 SVG 512x512

Instrucciones rápidas:

  1. Descarga los archivos SVG arriba
  2. Usa una herramienta online como svgtopng.com
  3. Convierte a PNG con transparencia
  4. Guarda como:
    • assets/icon-192.png
    • assets/icon-512.png
  5. O usa la herramienta de командной строки

Con ImageMagick (Linux/Mac):

convert -resize 192x192 assets/icon.svg assets/icon-192.png
convert -resize 512x512 assets/icon.svg assets/icon-512.png

Con Python (Windows):

# Requires: pip install cairosvg
import cairosvg
cairosvg.svg2png(url='assets/icon-192.svg', write_to='assets/icon-192.png')
cairosvg.svg2png(url='assets/icon-512.svg', write_to='assets/icon-512.png')
